# AI helper materials

These materials provide repository context for Codex and other AI assistants. They are supporting documentation, not the reviewer-facing instructions; the reviewer workflow is documented in the repository `README.md`.

## Contents

- `activity_replicate_comparison/`: generated inventories and summaries that show why the short-term and long-term data downloads need separate discovery logic.
- `questions/`: running questions about the reviewer implementation, analysis behavior, and follow-up work.
- `codex_reviewer_workflow.md`: concise decision guide for work on the two reviewer runners.
- `../docs/file_category_provenance.md`: source-versus-generated filename-category guide for the downloaded data, runner processing, and 1.3.1 analysis products.
- `../docs/reviewer_workflow_parity.md`: implementation map and test evidence for the historical-to-runner scientific core.

## Maintenance

Keep questions factual and tied to a file, workflow decision, or scientific assumption. Record answers or resolved decisions alongside the question when they become known. Do not place downloaded experimental data, credentials, or data-hosting access details in this directory.
